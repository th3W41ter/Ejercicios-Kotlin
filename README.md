# Ejercicios-Kotlin

**Autor:** Saul Walter Hernandez Del Angel
**Descripción:** Ejercicios de fundamentos de programación y Programación Orientada a Objetos (POO) desarrollados en Kotlin desde Visual Studio Code.

## Lista de ejercicios incluidos
- **Ejercicio 01:** Información de un usuario (Variables y tipos de datos)
- **Ejercicio 02:** Calculadora de almacenamiento (Operadores aritméticos y tipos numéricos)
- **Ejercicio 03:** Registro de una compra dentro de una aplicación (Entrada de datos y operaciones)
- **Ejercicio 04:** Validación de acceso a una aplicación (Condicionales `if` y `else`)
- **Ejercicio 05:** Menú de configuración de una aplicación (Estructura `when`)
- **Ejercicio 06:** Control de intentos de inicio de sesión (Ciclo `while`)
- **Ejercicio 07:** Consumo de batería (Ciclo `for` y acumuladores)
- **Ejercicio 08:** Calculadora mediante funciones (Funciones, parámetros y retorno)
- **Ejercicio 09:** Validación de información de registro (Funciones y valores booleanos)
- **Ejercicio 10:** Primera clase y creación de objetos (Clases, propiedades y objetos)
- **Ejercicio 11:** Constructores (Constructor primario)
- **Ejercicio 12:** Encapsulamiento (Modificadores de acceso y protección de propiedades)
- **Ejercicio 13:** Herencia de dispositivos (Herencia)
- **Ejercicio 14:** Polimorfismo en notificaciones (Sobrescritura de métodos)
